Project Repositories

This project spans three (3) repositories, each holding a distinct part of the work. The documentation repo — this site — carries the proposal, schedule, branding, and write-up. The experiments repo holds research code: baselines, prototypes, hyperparameter sweeps, and exploratory notebooks. The software repo holds the deployed application itself: frontend, backend, worker, and calibration logic. Each can be browsed independently, but they reference one another, and together they make up the full capstone deliverable.
